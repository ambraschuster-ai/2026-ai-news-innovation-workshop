Get Set Up: Deploy to Vercel

Before you build, get a live URL for your project. Same platform this workshop site itself deploys on.

  • Sign up free at vercel.com/signup with your GitHub account.
  • Add New > Project, import your project's repo.
  • In a subfolder, not the repo root? Set Root Directory before deploying.
  • Leave settings on auto-detected defaults, click Deploy.
  • Save the live URL, you'll want it for your submission card.
