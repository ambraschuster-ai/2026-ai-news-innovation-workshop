Skills & Best Practices

Package your expertise so it doesn't need re-explaining.

11:40 AM·40 MIN·Lecture
01

What a Skill Is

A reusable, filesystem-based resource: a folder of instructions, scripts, and reference material, organized roughly like an onboarding guide.

A prompt is conversation-level, for one task. A Skill loads on demand. A 14-skill journalism collection (AP style, source verification, FOIA templates) already exists, free to install.

02

When You'd Know You Need One

Every new chat, you type the same three sentences explaining a README format. Four times now, once per session.

That's the moment: not "this seems complicated," but "I've explained this before, and I'm about to explain it again." Same signal in reverse, too, if Claude keeps making the same small mistake you keep correcting.

Highlight the pattern to Claude, ask if a Skill is the right call, or just tell it to make one. Review what it builds.

03

Build One

Five steps, from noticing you need one to actually trusting it.

  1. 1

    Notice the pattern

    Same test as CLAUDE.md. Explained twice, or corrected twice.

  2. 2

    Direct Claude to build it

    Tell Claude the pattern, ask if a Skill is the fix. Claude sets up the folder and SKILL.md itself.

  3. 3

    Review the description it wrote

    Read it critically: specific enough to trigger reliably? Gotchas from real, watched failures?

  4. 4

    Test it two ways

    Ask a matching question, then invoke it directly by name.

  5. 5

    Stress-test it honestly

    Real examples, not abstract rules. Then a fresh conversation, messy input.

04

Testing It For Real

Hand your Skill a messy, real case, not the clean example you had in mind while writing it.

When it breaks, that's information, not failure. Add what happened to Gotchas, test again. A couple of corrections is normal. Patching the same Skill five or six times without rereading it start to finish is the patch spiral: stop and rebuild from what actually failed instead.

Installing skills from strangers
Shared skill repos have shipped credential-stealing malware. Fix: read before installing.
