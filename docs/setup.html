Day 1

1. Claude Desktop

The app you'll use on Day 1. It's a chat, research, and coding environment, all in one place.

2. Git

A small background tool used by Claude and in coding to keep track of changes to your work. You won't interact with it directly, but the Code tab won't open without it.

  • On a Mac: open the Terminal app. You can find it using the Spotlight search (Command + space bar) and typing Terminal, then hit Enter. In the window that opens, type git --version and press Enter. If it prints a version number, you're done. If it offers to install developer command line tools, accept and let it finish.

    On Windows: download and install Git for Windows, then reopen Claude Desktop.

3. GitHub

GitHub is the website where your work lives online and gets submitted. You'll learn how to connect it to your computer in two ways. But first, make an account.

That's everything you need for Day 1. If anything above didn't work, stop here and email Andrew (andrew.calderon@journalism.cuny.edu) and Adiel (adiel.kaplan@journalism.cuny.edu). Tell us which step you got stuck on and what you saw.
