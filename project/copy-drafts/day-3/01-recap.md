## 4. Platforms You'll See

Not a tutorial, just names worth recognizing. These are platforms other people in this program have reached for once a project outgrows a local prototype.

- **Vercel:** where a lot of these projects actually deploy. You'll set up a free account and deploy your own project in Build Time later this morning.
- **Chainlit:** a framework peers have used specifically for chatbot-style projects, when the product is mostly a conversation.
- **Supabase or Turso:** lightweight options for when a project needs to actually persist data instead of starting fresh every session.

Chainlit and Supabase/Turso, you don't need today. Worth knowing the names so they're not a total surprise the first time someone mentions one.
